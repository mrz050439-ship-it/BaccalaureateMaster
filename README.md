# Baccalaureate Master — منصة البكالوريا المصرية

تطبيق أندرويد أصلي (Java خالص، بدون أي مكتبات خارجية، بدون AndroidX) لمنصة تعليمية
تغطي نظام البكالوريا المصرية: 4 مسارات (الطب وعلوم الحياة، الهندسة وعلوم الحاسب،
الأعمال، الآداب والفنون) × 3 سنوات.

الإصدار الحالي: **v1.4** — 100% بدون إنترنت بعد التثبيت، بدون تسجيل حساب، كل
المحتوى مجاني ومفتوح لكل الطلاب.

## التحميل

آخر إصدار جاهز (APK): من صفحة
[Releases](https://github.com/mrz050439-ship-it/BaccalaureateMaster/releases).

## المحتوى

- شاشة بداية بتصميم مميز + دخول مباشر باسم الطالب فقط (محلي، بدون سيرفر).
- الرئيسية: المسارات الأربعة بألوان وهوية بصرية لكل مسار.
- شاشة المسار: السنوات الثلاث (الأولى والتانية متاحة، التالتة "قريبًا" لأن منهجها
  الرسمي لم يصدر بعد).
- شاشة المواد: المواد الأساسية + مواد التخصص حسب القرارات الوزارية، مع توضيح صريح
  لأي مادة منهجها الرسمي غير متاح حاليًا.
- شاشة الكورس: الوحدات والدروس بمحتوى الترم الأول من كتب الوزارة الرسمية، مع علامة
  إتمام لكل درس.
- شاشة الدرس: صفحات الكتاب الرسمي كصور عالية الجودة + ملزمة PDF تُولَّد على الجهاز
  لكل درس قابلة للتحميل والمشاركة. بدون فيديو وبدون اختبارات.
- شاشة "نظام البكالوريا": شرح النظام كاملًا (المجموع 600، شكل الامتحان، فرصتا
  الامتحان، شرط 60%).

المحتوى المتاح حاليًا (الصف الثاني الثانوي، الترم الأول): اللغة العربية، الفيزياء،
الكيمياء، تاريخ مصر، علم النفس. المواد غير المتاحة موسومة بوضوح داخل التطبيق.

## البناء في CodeAssist (على الموبايل)

1. حمّل الكود (Code → Download ZIP) وفك ضغطه.
2. افتح CodeAssist ثم Import project واختر مجلد BaccalaureateMaster.
3. شغّل Build. المشروع Java خالص بدون مكتبات خارجية ولا AndroidX.

## البنية

- `app/src/main/java/com/omar/baccalaureatemaster/` — كود التطبيق (Activities،
  البيانات، مولّد الملازم PDF).
- `app/src/main/assets/lessons/` — صفحات الكتب الرسمية (WebP) لكل درس.
- ملفات Gradle مصرّحية (declarative) متوافقة مع AGP 8.5.2 و Gradle 8.9.
